# pyksift

Python realization of [ksift](https://github.com/dvera/ksift)

## Installation
- Install conda (Miniconda or Mambaforge).
- Clone repository `https://github.com/alermol/pyksift`
- Change directory `cd pyksift`
- Create the environment: `conda env create -f environment.yml`.
- Activate it: `conda activate pyksift`.
- You are ready to go!
